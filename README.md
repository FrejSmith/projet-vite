# Exercices JavaScript avec Vite

Un seul projet Vite, un dossier par exercice :

- `Exo1` : notification « J'aime » qui disparaît 3 secondes après le dernier clic
- `Exo2` : chronomètre avec un bouton Démarrer / Pause / Reprendre
- `Exo3` : ajout de tags (sans doublon) avec résumé automatique

## Lancer le projet

```bash
npm install
npm run dev
```

Puis ouvrir l'adresse affichée dans le terminal (par défaut http://localhost:5173) et choisir un exercice sur la page d'accueil.
